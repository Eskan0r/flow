# Gameplay and performance audit — October 29, 2026

Reviewed locally with an independent GPT-6 Astra audit. Rule reference:
[Big Duck Games' Flow Free description](https://www.bigduckgames.com/flowfree):
connect matching colors, connect every pair, fill the board, and break pipes
when paths cross or overlap. Square, hex, warp, wall and chain variants keep
their existing topology. Undo follows the requested project rule: preserve
spent moves, without adding a move or refunding hint usage.

## Fixed

| Issue | Result |
| --- | --- |
| Refresh/navigation resets unfinished daily attempts | Persist and validate paths, counters, hints, history and clock; checkpoint live drags and flush on page lifecycle events. |
| Undo restores old moves and hint usage | Undo changes the board while preserving current counters; later drawing counts normally. |
| Daily seeds entered as custom games or resized through settings | Resolve all daily seeds through the canonical daily loader and saved attempt. |
| Undo over a completed daily's win dialog | Ignore game shortcuts over the modal and block completed-daily undo. |
| Already completed daily receives another result write | Recheck completion before recording a win. |
| Generator retry salt changes public puzzle identity | Keep the requested seed stable through internal retries. |
| Unbounded or mismatched URL dimensions | Normalize finite integer dimensions before constructing topology to match generator bounds. |
| Streak skips a day around spring daylight saving time | Subtract calendar days instead of fixed 24-hour periods. |
| Custom replay loses rectangle/warp/chain settings | Preserve full custom geometry and mode flags. |
| Different topology variants share best scores | Separate variant score keys while preserving classic and canonical daily keys. |
| Archived result copies today's share text | Pass the result's date into the copy callback. |
| Stale displayed clock and zero-time resumed hint win | Reset the display on load, restore elapsed time, and record accumulated time on win. |
| Cancelled drag leaves solved board unawarded | Check victory and synchronize state on cancellation/lost capture. |
| A second pointer replaces an ongoing stroke | Keep input owned by its original pointer. |
| Right click starts a drawing stroke before clearing | Only primary-button input starts a stroke. |
| Unnecessary rendering and storage reads | Avoid reallocating unchanged canvas dimensions, skip movement within the current cell, remove duplicate release redraws, cache pack progress per revision. |
| Clock interval continues in menus or after destruction | Stop intervals when leaving play and clean up timers/listeners on destruction. |
